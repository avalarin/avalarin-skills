# avalarin-skills

Плагин для [Claude Code](https://claude.ai/code) с набором скилов и агентов для автоматизации цикла разработки: от создания ветки до PR.

## Установка

```bash
claude plugins add avalarin/avalarin-skills
```

## Флоу разработки

### 1. Создание worktree — `/worktree-init`

Начало работы над фичей. Скил создает новую git-ветку и worktree в `.claude/worktrees/`, копирует конфиги и открывает новую вкладку в iTerm2 с двумя панелями: Claude и терминал.

```
/worktree-init
```

### 2. Разработка фичи — `/feature-dev`

Управляемая разработка: анализ кодовой базы, планирование, реализация и тесты. Скил ведет по шагам и задает уточняющие вопросы.

```
/feature-dev добавить кеширование для API-запросов
```

### 3. Код-ревью — `/code-review`

Запускается автоматически после завершения задачи в `/feature-dev`, но можно вызвать вручную в любой момент. Отправляет git diff на проверку агенту `code-reviewer`, который анализирует изменения по чеклисту: корректность, безопасность, производительность, читаемость.

```
/code-review
```

### 4. Создание PR — `/create-pr`

Коммитит незакоммиченные изменения, пушит ветку, создает pull request и ждет прохождения CI. Если CI падает — показывает ошибки и предлагает починить. Скил не привязан к конкретному хостингу: работает через подключаемые провайдеры (GitHub из коробки, можно добавить Bitbucket, GitLab и др. через файл провайдера — см. `plugin/skills/create-pr/references/provider-contract.md`).

```
/create-pr
```

## Вспомогательные скилы

| Скил | Описание |
|------|----------|
| **receiving-code-review** | Определяет, как Claude обрабатывает результаты код-ревью: техническая верификация замечаний вместо слепого выполнения, проверка перед внесением изменений. |
| **test-dev** | Управляемая разработка тестов: анализ покрытия, выбор стратегии, написание unit/integration/UI-тестов. |

## Агенты

Агенты — это фоновые подпроцессы Claude с собственным контекстом, набором инструментов и памятью. Их стоит использовать когда задача требует изолированной работы (чтобы не засорять основной контекст), параллельного выполнения нескольких задач, или когда агенту нужно накапливать знания между запусками (например, запоминать типичные ошибки в проекте).

| Агент | Описание |
|-------|----------|
| **code-reviewer** | Проверяет изменения в заданном git diff range по чеклисту качества. Запускается скилом `code-review`. |
| **software-engineer** | Реализует код, фиксит баги, решает технические задачи. Перед реализацией ищет решения в документации и на форумах, запоминает рабочие рецепты. |
| **system-analyst** | Анализирует проект и предоставляет информацию: варианты решений, описание задач, исследование кодовой базы. Не вносит изменений в код. |

## Устаревшие скилы

| Скил | Статус |
|------|--------|
| **plan-creator** | Устарел. Функциональность планирования встроена в `/feature-dev` и агент `system-analyst`. |
